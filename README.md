# Квартал

Онлайн-перестрелка в городе с видом сверху. Играется в браузере на телефоне и компьютере, друзья заходят по ссылке на комнату.

- каждая комната - новая случайная карта 128x128 м: дороги, дома с комнатами, дверями и окнами, парки с прудами, парковки, стройки;
- разрушается всё, кроме границы карты: стёкла, заборы, ящики, деревья, кирпичные стены; бочки и машины взрываются, у разбитых домов обрушивается крыша;
- оружие с патронами появляется на карте примерно раз в 15 секунд, аптечки и бронежилеты - реже;
- камера идёт за игроком, видно около 15 м вокруг, внизу миникарта;
- все против всех с возрождением; если людей меньше четырёх, комнату добирают боты.

## Запуск

```
npm install
npm start
```

Сервер слушает `PORT` (по умолчанию 8080). Проверка живости - `GET /health`.

## Устройство

- `public/shared.js` - общие константы (оружие, прочность клеток) и физика движения, один файл для сервера и браузера;
- `game/mapgen.js` - генератор города;
- `game/room.js` - комната: стрельба, взрывы, урон, разрушение, оружие на карте, рассылка состояния 15 раз в секунду;
- `game/bots.js` - боты (поиск пути A*);
- `public/game.js` - клиент: управление (клавиатура и мышь, экранные джойстики), камера, отрисовка, миникарта, звук.

Шаги игрока считает браузер, сервер проверяет скорость и стены и при нарушении возвращает игрока назад. Всё остальное считает только сервер.

## Тесты

```
npm test                         # 60 карт + 3 минуты боя без сети
node test/e2e.cjs <адрес>        # компьютер и телефон в одной комнате (нужен Playwright)
KV_DEBUG=1 npm start             # отладочные команды для test/visual.cjs, на хостинге не включать
```

## Хостинг

Render, бесплатный тариф, регион Frankfurt (`render.yaml`). Бесплатный сервер засыпает через 15 минут без игроков, первое открытие после паузы занимает до минуты.
