# Квартал

Онлайн-перестрелка в городе с видом сверху. Играется в браузере на телефоне и компьютере, друзья заходят по ссылке на комнату.

- каждая комната - новая случайная карта 128x128 м: дороги, дома с комнатами, дверями и окнами, парки с прудами, парковки, стройки;
- разрушается всё, кроме границы карты: стёкла, заборы, ящики, деревья, кирпичные стены (дыры расширяются); бочки и машины взрываются, у разбитых домов обрушивается крыша;
- оружие с патронами появляется на карте примерно раз в 15 секунд; в ящиках тоже лежат оружие, патроны, аптечки и броня, ящики появляются снова;
- машины с водителями ездят по своим полосам, поворачивают на перекрёстках, тормозят и сигналят - но выбежавшего прямо под колёса собьют;
- любую машину можно угнать (кнопка с машинкой или F), рулить, стрелять из окна, таранить; лёгкие препятствия машина проламывает, разбитая горит и взрывается;
- рывок (кнопка или Shift) тратит выносливость, на рывке не стреляют;
- камера держит игрока в центре, видно около 11 м вокруг; слева вверху радар, по нажатию - вся карта;
- все против всех с возрождением; если людей меньше четырёх, комнату добирают боты (они тоже угоняют машины, но стреляют неметко).

## Запуск

```
npm install
npm start
```

Сервер слушает `PORT` (по умолчанию 8080). Проверка живости - `GET /health`.

## Устройство

- `public/shared.js` - общие константы (оружие, прочность клеток, машины) и физика людей и машин, один файл для сервера и браузера;
- `game/mapgen.js` - генератор города;
- `game/room.js` - комната: стрельба, взрывы, урон, разрушение, оружие и ящики, рывок, рассылка состояния 15 раз в секунду;
- `game/vehicles.js` - машины: движение по полосам и перекрёсткам, угон, удары, пожар и взрыв;
- `game/bots.js` - боты (поиск пути A*, вождение);
- `public/game.js` - клиент: управление (клавиатура и мышь, экранные джойстики), камера, отрисовка, радар, звук.

Шаги игрока и руль его машины считает браузер, сервер проверяет скорость и стены и при нарушении возвращает назад. Всё остальное считает только сервер.

## Тесты

```
npm test                              # 60 карт + 3 минуты боя без сети, посадка в машину
node test/e2e.cjs <адрес>             # компьютер и телефон в одной комнате (нужен Playwright)
KV_DEBUG=1 npm start                  # отладочные команды для test/drive.cjs и test/visual.cjs, на хостинге не включать
node test/drive.cjs <адрес>           # машины, рывок, радар, кнопки на телефоне
```

## Хостинг

Render, бесплатный тариф, регион Frankfurt (`render.yaml`). Сервис подключён как публичный репозиторий, поэтому после `git push` нужно нажать «Manual Deploy → Deploy latest commit». Бесплатный сервер засыпает через 15 минут без игроков, первое открытие после паузы занимает до минуты.
